# CloudPulse AI

## Project Overview
CloudPulse AI predicts cloud costs and detects unusual spending using machine learning.

## Features
- Cloud cost forecasting
- Anomaly detection
- Alert explanations
- Risk prioritization
- Model evaluation
- Interactive dashboard

## Technologies
- Python
- Pandas
- Scikit-learn
- Streamlit
- AWS
- Docker
